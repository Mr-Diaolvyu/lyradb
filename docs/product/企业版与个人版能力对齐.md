# 企业版与个人版能力对齐

核验日期：2026-09-24。版本：3.2.0。

依据[产品定位](产品定位.md)、[系统架构](../../wiki/系统架构.md)、[数据库地图与血缘](数据库地图与血缘.md)及实际调用路径核对。个人版为原生 Swing 本机直连，企业版为 Spring Boot + Vue 托管连接；对齐基础数据工作能力及可信边界，保留各自的权限和运行方式。

## 应对齐能力

| 能力 | 个人版执行点 | 企业版执行点 | 结果 |
|---|---|---|---|
| 9 类驱动、基础元数据 | `NativeConnectionManager` | `DataSourceService`、`EnterpriseMetadataCatalogService` | 共用 core 驱动和模型；具体厂商功能以驱动能力为准 |
| 连接参数、敏感值保护、迁移 | `DesktopStateStore`、`ConnectionTransferService` | `CredentialService`、`EnterpriseConnectionTransferService` | 共用连接包和 Excel 编解码；企业导出附加审批 |
| 表结构、注释、DDL、分区、受限预览 | `TableInspectorPanel` | `TableInspectionView`、`EnterpriseQueryService` | 共用核心检查器；MaxCompute 默认不自动读数据 |
| SQL 编辑、补全、格式化、结果字段显示 | `SqlWorkspacePanel` | `SqlEditor`、`EnterpriseQueryView` | 两端具备，UI 各自实现，不承诺像素或排版相同 |
| SQL 安全检查 | `NativeConnectionManager` | `EnterpriseQueryService` | 共用 AST 和审核规则；个人主动确认，企业权限及审批不可绕过 |
| 精确取消当前 SQL | `SqlWorkspacePanel.cancel` | `EnterpriseQueryExecutionService`、查询页取消按钮 | 本版补齐；企业句柄绑定用户、工作空间和逻辑数据源，取消会停止后续脚本 |
| 普通数据库全范围 ER | `ErDiagramMetadataLoader` | `EnterpriseMetadataCatalogService.erDiagram` | 本版补齐；企业自动加载所选 Schema 的授权范围，移除手选 24 表限制，最多 2000 表并提示截断 |
| MaxCompute 真实表/字段血缘 | `ErDataMapDialog` | `EnterpriseLineageService`、`EnterpriseErDiagramView` | 本版补齐并共享 `DataWorksLineageClient`；企业遍历前过滤授权，返回前复检授权 |
| 血缘探查时机 | 本机连接保存策略 | 企业图谱窗口选择策略 | 手动、选根表后、每 30 分钟、每 6 小时；关闭窗口停止定时探查，企业策略仅在当前页面生命周期内保留 |
| AI 建议、显式元数据上下文 | `AiAssistantDialog`、`MetadataPreviewDialog` | `EnterpriseAiService`、`EnterpriseMetadataSnapshotService` | 显式附加元数据，输出不自动执行；企业附加当前授权复检 |
| 数据导出 | 原生 CSV 导出 | 企业 CSV/JSON 审批后导出 | 两端具备；企业保留脱敏、审批和审计 |

## 保留的产品差异

- 个人用户管理本机连接和密钥；企业用户只见逻辑数据源，由管理员管理凭据和授权。
- 个人版手动 JDBC 事务对应本机连接生命周期；企业共享连接不开放跨 HTTP 请求的手动事务，DML/表格修改通过审批和服务端事务执行。
- 企业 RBAC、用户生命周期、批量授权、脱敏、审批、审计、团队知识、受控只读 Agent、Gateway 和集中 Provider 不复制到个人端。
- 企业脚本库、加密历史和审批表格编辑属于企业工作流增强；个人端继续使用本机 SQL 工作台。现行设计未要求两端采用相同的脚本持久化或表格审批流程。
- 高阶 AI 默认开关及真实环境灰度边界遵循原设计；3.x 写入型 Agent 继续关闭。

## 验证边界

自动化覆盖完整授权 ER、表/字段血缘方向、未授权节点不返回也不继续探查、授权变化拒绝返回、SDK 错误脱敏，以及跨用户/跨工作空间取消、一次性执行、排队取消和精确 Statement 定位。前端组件回归覆盖 ER 自动加载、MaxCompute 手动默认、根字段选择和关闭窗口后停止定时器。

真实 DataWorks 结果取决于目标环境版本、RAM 权限与作业血缘采集；测试替身不代表真实项目血缘验收。取消请求不等于数据库已回滚，已发送写入的最终状态须按企业审批执行状态核对。

企业普通 SQL 句柄驻留在处理请求的服务节点。多节点部署须让准备、执行和取消使用同一会话亲和节点；重启后旧句柄失效。受控 Agent 原有的持久计划及跨节点取消机制独立保留。

DataWorks 契约依据：[官方 ListLineages 使用说明](https://help.aliyun.com/zh/dataworks/user-guide/data-blood-relationship-openapi-practice)，于 2026-09-24 核验；Java SDK 延用项目已锁定的 `dataworks_public20240518:8.8.5`。
