# LyraDB · 天琴智库产品定位

- 生效日期：2026-08-04
- 定位状态：当前唯一权威版本
- 适用范围：README、Wiki、产品页面、PRD、路线图、演示材料和对外介绍

## 一句话定位

> **LyraDB · 天琴智库是面向数据专业团队、可私有化部署的可信 AI 数据智库。它把多数据库、授权元数据、已验证知识和治理规则连接起来，让每个数据问题都得到有依据、可执行、可追溯的答案。**

## 我们解决什么问题

数据团队的真实任务通常被拆散在数据库客户端、数据平台、文档、群聊、审批系统和通用 AI 中。用户需要自己找表、猜字段、拼上下文、判断权限、修复 SQL，并承担模型错误和越权风险。

LyraDB 将这条链路重组为：

```text
提问 → 找证据 → 理解语义 → 形成计划 → 受控行动 → 留下回执 → 审核并沉淀知识
```

数据库编辑器、对象浏览器和结果网格继续存在，但它们承担人类检查、修改和接管任务的专业控制面，而不是产品的全部定位。

## 首要用户

### 滩头用户

同时使用 MaxCompute 与 MySQL、PostgreSQL、ClickHouse 等数据库，且关注私有化、业务语义、权限和 AI 安全的数据工程师、数据架构师与数据治理负责人。

### 次级用户

- 需要本地或离线 AI 辅助的个人数据专业用户；
- 负责知识审核、权限、审批和审计的数据管理员；
- 需要通过受控接口使用数据知识与只读计划能力的外部 Agent 开发者。

### 近期不作为核心目标

- 只需要简单聊天或通用企业文档问答的用户；
- 追求无人值守 DML、DDL 或跨系统自动写入的团队；
- 要求所有数据库厂商特性完全等深支持的市场。

## 核心价值

| 价值 | 产品机制 | 用户结果 |
|---|---|---|
| 有依据 | 授权元数据、`VERIFIED` 知识、证据引用和 Context Receipt | 知道答案从哪里来、缺少什么 |
| 可执行 | 类型化工具、只读计划、SQL 专业控制面 | 从建议进入可检查的任务计划 |
| 受约束 | 用户权限交集、Grant、AST、行数、时间、成本、确认和审批 | Agent 不能因模型指令扩大权限 |
| 可追溯 | 模型、知识版本、计划摘要、工具轨迹、审计和评测 | 能复盘谁在何时基于什么做了什么 |

## 差异化

LyraDB 不以菜单数量、模型数量或 Agent 数量竞争，而聚焦以下交叉区域：

1. **知识不是 RAG 附件**：业务术语、表字段、已验证问法、SQL、策略和证据都有状态、负责人和审核边界；
2. **Agent 不是管理员替身**：每次行动都受身份、资源、操作、成本和有效期约束；
3. **工作台不是旧包袱**：它是 AI 任务的人类专业控制面，支持检查、编辑、确认和接管；
4. **私有化不是附加选项**：本地原生端、私有模型和模型中立是产品设计前提；
5. **MaxCompute 不是普通 JDBC 方言**：分区、Project、成本和任务诊断形成专项证据链。

## 产品形态

| 形态 | 产品角色 | 当前边界 |
|---|---|---|
| 个人智库工作台 | 本地直连数据库、个人 AI 辅助和专业 SQL 控制面 | AI 输出不自动执行；知识以个人上下文为主 |
| 团队可信数据智库 | 团队知识、RBAC、治理、受控只读 Agent、评测和 Gateway | 高阶能力默认关闭，需真实环境灰度 |
| 移动治理伴侣 | 审批、告警、审计与任务接管 | 不在移动端加载 JDBC 或复制完整 SQL IDE |

## 能力成熟度

| 等级 | 含义 | 当前状态 |
|---|---|---|
| L0 建议 | 生成、解释、修复、优化和审查 SQL | 个人端与基础企业 AI 已具备 |
| L1 有据回答 | 引用已验证知识并明确未知 | 代码已实现，高阶开关默认关闭 |
| L2 受控只读行动 | 先计划、再确认、执行前复检并留回执 | 代码已实现，待真实数据库灰度 |
| L3 团队学习 | 审核知识、自动评测、基于真实失败持续改进 | 代码已实现，待设计伙伴验证 |
| L4 受控写入 | 写操作、补偿、幂等、审批和责任闭环 | 3.x 硬关闭，不属于当前承诺 |

## 安全与表达红线

- 未授权元数据或数据值不得进入模型；
- 模型推断不得直接升级为已验证业务知识；
- 所有真实读取必须经过当前用户权限、Grant 和执行前复检；
- DML、DDL、授权变更和大规模导出不进入当前 Agent 自动执行范围；
- 未完成真实 Provider、数据库、MaxCompute 和 MCP 验收前，不宣称高阶 AI 生产可用；
- 产品宣传不使用“全自动”“零错误”“无需人工”。

## 标准短介绍

### 10 秒

LyraDB · 天琴智库让数据团队基于已验证知识和最小权限 Agent，获得有依据、可执行、可追溯的数据答案。

### 30 秒

LyraDB 不是数据库客户端旁边的聊天框。它把多数据库工作台、团队知识、权限治理和受控 Agent 连接成一个可私有化的数据智能入口：先找证据，再给计划，在用户权限和成本边界内行动，并为每一步留下可审核回执。
