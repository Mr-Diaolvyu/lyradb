# 数据库地图与血缘

## 1. 产品目标

数据库地图不再把所有引擎都包装成同一种 ER 图：

| 数据源 | 默认视图 | 关系来源 | 用户入口 |
|---|---|---|---|
| MySQL、PostgreSQL、Oracle、SQL Server、SQLite、ClickHouse 等普通数据库 | 所选数据库 / Schema 的全范围 ER 图 | 驱动返回的真实主键、外键与字段元数据 | 选择范围后自动加载，无需手工选表 |
| MaxCompute | 数据血缘与字段血缘 | DataWorks `ListLineages` 返回的真实血缘边 | 先选择根表，再手动或按策略探查 |

两种模式都不根据表名、字段名或 SQL 文本猜测关系。没有外键或 DataWorks 血缘时，画布允许只有节点、没有连线。

## 2. 表工作台加载规则

打开表或视图后，加载顺序为：

1. 字段结构与字段注释；
2. 表注释；
3. 普通数据库的索引与约束；
4. DDL 与受限预览 SQL；
5. 数据预览。

元数据读取和数据预览使用独立后台任务，慢查询不会再阻止字段与注释显示。单项元数据失败只标记该项，不清空已经成功读取的内容。

- 普通数据库：元数据完成后自动加载最多 200 行只读数据。
- MaxCompute：默认不自动读数据，用户点击“加载前 100 行”后才执行 `TABLESAMPLE` 预览，以降低无分区扫描风险。
- 表注释优先读取 `DESCRIBE EXTENDED`，兼容双列结果和单列多行结果；取不到时再从原生 `SHOW CREATE TABLE` 降级提取。
- 字段注释在 JDBC `REMARKS` 为空时使用 `DESCRIBE` 补齐。

## 3. 普通数据库全范围 ER

选择数据库、Catalog 或 Schema 后，客户端会：

1. 递归枚举范围内的全部表和视图；
2. 立即绘制表节点骨架；
3. 在后台补齐字段、主键和外键；
4. 只根据真实外键绘制方向关系；
5. 支持在当前画布按表名、命名空间、字段名或字段注释过滤；
6. 支持缩放、适应画布和导出 PNG。

单个范围设置 2,000 张表 / 视图的桌面安全上限。达到上限时状态栏会明确提示；建议再按更细的 Schema 分范围查看，避免生成不可操作的超大画布。

## 4. MaxCompute 表血缘与字段血缘

### 4.1 根对象与方向

- 表血缘：可选择一张或多张根表，查询仅上游、仅下游或上下游。
- 字段血缘：先选择根表，再选择一个根字段，按字段实体继续查询。
- 默认展开深度为 2，最多展示 120 个节点，避免大型数仓无边界展开。

实体 ID 遵循 DataWorks 官方格式：

```text
maxcompute-table:::<project>::<table>
maxcompute-column:::<project>::<table>::<column>
```

上游探查把根实体作为 `DstEntityId`，下游探查把根实体作为 `SrcEntityId`。画布只使用 API 返回的 `SrcEntity → DstEntity` 方向。

### 4.2 探查时机

连接配置和血缘工具栏都可以设置：

- 仅手动（默认）；
- 选择根表后；
- 每 30 分钟；
- 每 6 小时。

定时策略只在血缘窗口打开且已选择根表时执行，不在后台静默创建全局任务。切换策略会保存到当前连接配置。

### 4.3 权限与数据来源

使用血缘前需要：

- 当前 AccessKey 对 DataWorks `ListLineages` 有调用权限；
- DataWorks 版本和工作空间支持数据血缘；
- MaxCompute 执行 Project、地域与 DataWorks Endpoint 正确；
- 使用 STS 时填写 Security Token。

连接页默认从 MaxCompute Endpoint 推断地域，也可填写 `dataWorksRegionId` 和 `dataWorksEndpoint` 覆盖。AccessKey Secret 与 Security Token 按敏感字段加密落盘。

DataWorks 血缘来自平台实际解析的调度作业关系。临时查询或平台未采集的作业可能没有血缘；LyraDB 会显示空结果或权限错误，不会生成推测关系。

## 5. 当前验证边界

本地自动化已覆盖 MaxCompute 表/字段注释降级、表/字段实体 ID、上下游方向、探查策略，以及普通数据库超过旧 24 表限制的加载行为。完整 Maven 反应堆共 405 项测试通过。

真实 DataWorks 血缘结果仍需要在具备相应版本、RAM 权限和调度作业血缘的 MaxCompute 环境中核对；代码测试替身不能替代真实作业与控制台结果。
