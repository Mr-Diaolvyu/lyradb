工程结构、配置、接口和移动端实现仍由 [项目 Wiki](../wiki/首页.md) 承载。技术文档描述真实实现，不因产品定位升级而夸大未验证能力。

## 状态规则

- “已实现”：当前代码存在明确执行点；
- “已验证”：有当前分支自动化、构建或真实环境证据；
- “默认开放”：对应能力默认启用且完成上线门禁；
- “规划”：尚未实现或尚无充分验证证据。

高阶 AI 目前为“代码实现并通过自动化验证，待真实环境灰度”，不等同于已发布或生产可用。
