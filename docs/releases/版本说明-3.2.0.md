# LyraDB 3.2.0

本版补齐个人版与企业版的基础工作台能力，并发布当前工作区已有的企业管理与 SQL 工作流改进。

## 主要变化

- AI 默认入口简化为选择数据源、按需添加表结构和提问；受控读取、MaxCompute 预检与知识草稿保留在高级工具入口。
- AI 问答、智能找表及结构采集支持服务端后台执行，展示等待动画、状态及耗时；切换页面或刷新后可恢复结果。完成结果保留一小时，当前服务进程重启后清空。
- 修复元数据采集的 Schema 通配符与 MySQL 库名匹配；未采集到表时明确报错，不再创建空快照并显示成功。
- 企业普通 SQL 新增精确取消；句柄绑定用户、工作空间和数据源，支持排队取消并停止后续脚本。
- 企业 ER 自动覆盖所选 Schema 的授权对象，移除手选 24 表限制；最多 2000 表，达到上限明确提示。
- 企业 MaxCompute 新增 DataWorks 真实表/字段血缘、上下游选择和窗口内探查策略；两端复用同一核心客户端，企业仅返回授权对象和关系。
- 企业 SQL 工作台增加多脚本、多结果、执行进度、脚本保存、加密历史、目录搜索及审批表格编辑。
- 企业管理增加批量授权、连接测试、角色修改、用户软删除，以及 AI 脱敏规则草稿和 Provider 鉴权提示。
- 修复动态驱动加载错误引入测试与可选依赖的问题，恢复 SQLite 首次连接的运行依赖解析；两端共用修复。
- 统一版本、构建脚本和发布说明来源，保留正式源码与测试，清理临时验证和回溯材料。

完整核对见[企业版与个人版能力对齐](https://github.com/Mr-Diaolvyu/lyradb/blob/v3.2.0/docs/product/企业版与个人版能力对齐.md)。

## 下载

个人用户下载并完整解压 `LyraDB-3.2.0-windows-x64-portable.zip`，运行 `LyraDB/LyraDB.exe`。

| 附件 | 用途 |
|---|---|
| `LyraDB-3.2.0-windows-x64-portable.zip` | Windows x64 原生个人版，含运行时 |
| `LyraDB-Enterprise-Server-3.2.0.jar` | 含 Vue 前端的企业 B/S 服务端 |
| `lyradb-frontend-3.2.0.cdx.json`、`lyradb-java-3.2.0.cdx.json` | CycloneDX 软件组成清单 |
| `SHA256SUMS.txt` | 附件完整性校验 |

## 升级与边界

企业升级前备份元数据库。Flyway V8/V9 增加脚本、历史与用户软删除结构；降级不能只替换旧 JAR，须恢复匹配的元数据库备份。普通 SQL 的准备、执行和取消须路由到同一服务节点，多节点使用会话亲和。

DataWorks 血缘需要官方 Endpoint、RAM 权限与实际采集的血缘。空关系不代表没有上下游。取消最终效果取决于数据库驱动，取消按钮不承诺写入已经回滚。

企业 RBAC、审批、脱敏、审计及团队 AI 边界继续生效。高阶 AI 的真实 Provider、数据库和外部客户端灰度仍按现有计划执行；3.x 写入型 Agent 继续关闭。iOS/HarmonyOS 本轮只统一版本，未作原生实机构建验收。

## 发布验证

流水线要求前端 Lint、类型检查、测试和构建，Java 测试，Windows EXE 冒烟，Android Debug 检查及构建，Docker 企业空库启动、登录和版本读回，以及附件 SHA-256、SBOM 和来源证明成功后才创建 Release。
