# ADR-004：AI 原生智库完成契约

- 产品定位：[LyraDB · 天琴智库](../product/产品定位.md)

- 状态：已接受，代码已实现，待真实环境验收
- 日期：2026-08-03
- 适用分支：`codex/ai-native-foundation`

## 决策

LyraDB 的“AI 原生”不以聊天入口或类名为完成标志，而以以下可执行契约为准：

1. 模型可以在有限步数内发现并调用类型化只读工具；未知工具、越权资源、超预算和超步数全部失败关闭。
2. 模型只能创建只读计划，不能代替用户确认执行；计划正文加密持久化，确认必须单次消费并在执行前重新授权。
3. 知识只允许经人工审核的 `VERIFIED` 资产进入模型上下文；自动摄取只能生成草稿。
4. 知识检索采用来源过滤、关键词相关度和可选语义向量的混合排序，并在回执中说明降级原因。
5. 质量门禁必须能自己调用模型产生观测，不接受仅由客户端声明“已经通过”。
6. MaxCompute 分区、扫描量、成本和任务状态必须区分实时观测与调用方声明；无真实连接时不得伪装为实时结果。
7. Agent Gateway 同时支持 MCP `2026-07-28` 与受控 REST；工具列表按令牌 Scope 返回，所有状态句柄每次重新鉴权。
8. AI 调用、工具调用、限流、成本和失败必须有可读取指标；敏感正文、密钥和原始错误不得进入指标标签。
9. 企业内网模型只能在显式开启、精确主机白名单和受限地址策略下接入；默认仍拒绝私网出站。
10. 写入型 Agent 在独立 4.0 门禁通过前没有工具、端点或可启用配置。

## 完成证据

每项契约都必须同时具备：

- 服务端强制点；
- 正向与失败关闭测试；
- 用户可见的状态或 Context Receipt；
- 默认关闭或受依赖约束的功能开关；
- 与当前权限、审计和脱敏链路的回归验证。

实现落点包括 V3-V7 数据库迁移、持久化只读计划状态机、单次 MaxCompute 预检、MCP/REST 双协议网关、自动黄金集、知识摄取草稿、进程指标与私有模型出站策略。前端已提供编排轨迹、人工确认、知识摄取、自动回归、运行指标和 Provider 部署模式入口。

计划的授权、摘要、AST 和权限包络会在持久化认领后再次校验；这保证重启恢复不会复用旧授权。进入完成、失败、取消或过期终态后，计划 SQL 密文被清除。

真实模型、数据库与 MaxCompute 账户属于环境验收证据。代码测试替身只能证明协议和边界，不能替代真实业务口径、账单或方言验证。

## 明确不做

- 不让模型调用任意 Shell、任意 URL 或任意工具名。
- 不将自动摄取内容直接发布为团队知识。
- 不把调用方声明的成本标记为 MaxCompute 实时估算。
- 不因 MCP 客户端要求而扩大 Gateway 令牌绑定的工作空间、用户或 Grant。
- 不开放 DML、DDL、审批代签或无人值守写入。
