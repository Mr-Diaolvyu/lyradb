# 配置说明

## 配置文件结构

```
backend/src/main/resources/
├── application.yml       # 公共配置（所有环境共享）
├── application-dev.yml   # 开发环境（H2 Console 开启）
├── application-prod.yml  # 生产环境（安全加固）
└── drivers.json          # JDBC 驱动注册表
```

## 环境变量

| 变量名 | 默认值 | 说明 |
| -------- | -------- | ------ |
| `SPRING_PROFILES_ACTIVE` | `dev` | 激活的 Spring Profile |
| `LYRADB_EDITION` | `personal` | 发行版：`personal` / `enterprise` |
| `JASYPT_PASSWORD` | 无（prod 必填） | Jasypt 凭据加密密钥，生产环境必须注入 |
| `LYRADB_DDL_AUTO` | `update` | JPA DDL 策略（Docker Compose 中可覆盖） |
| `LYRADB_USER` / `LYRADB_PASSWORD` | 无 | 企业版生产管理员账号（prod 必须注入） |
| `app.desktop.tray-enabled` | `false` | 桌面版系统托盘开关（jpackage 打包时经 `--java-options` 注入为 true） |

## application.yml 核心配置

### 服务器

```yaml
server:
  port: 8080                    # 服务端口
  servlet:
    context-path: /api          # API 上下文路径
```

### 应用自定义配置 (app.*)

```yaml
app:
  edition: personal             # 发行版（personal/enterprise）
  driver-cache-dir: ~/.lyradb/drivers  # 驱动缓存目录
  max-connections-per-db: 10    # 每个数据库最大连接数
  max-query-rows: 10000         # 查询结果最大行数
  query-timeout-seconds: 60     # SQL 执行超时（秒），0=无限制
  audit:
    mask-sql: false             # 审计日志是否脱敏 SQL
```

### JPA / H2

```yaml
spring:
  jpa:
    show-sql: false
    properties:
      hibernate:
        format_sql: true
```

H2 数据库文件存储在 `backend/data/lyradb.mv.db`。

### 文件上传（multipart）

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 50MB       # 单文件上限（数据导入 CSV/JSON）
      max-request-size: 50MB    # 单请求总上限
```

### Jasypt 加密

```yaml
jasypt:
  encryptor:
    algorithm: PBEWithMD5AndDES
    iv-generator-classname: org.jasypt.iv.NoIvGenerator
```

用于加密存储数据库连接凭据。加密密钥由各 profile 配置提供。

### Jackson 序列化

```yaml
spring:
  jackson:
    serialization:
      write-dates-as-timestamps: false   # 日期输出 ISO 格式
    default-property-inclusion: non_null  # 忽略 null 字段
```

### 日志级别

```yaml
logging:
  level:
    io.github.lexaquila.lyradb: DEBUG
    org.hibernate.SQL: WARN
    org.springframework: INFO
```

## Profile 差异

| 配置项 | dev | prod |
| -------- | ----- | ------ |
| H2 Console | 开启 | 关闭 |
| CORS | 允许 localhost:5173 | 严格限制 |
| 日志级别 | DEBUG | INFO/WARN |

## drivers.json 驱动注册表

定义所有支持的数据库驱动信息：

```json
{
  "drivers": [
    {
      "id": "mysql",
      "name": "MySQL",
      "driverClass": "com.mysql.cj.jdbc.Driver",
      "urlTemplate": "jdbc:mysql://{host}:{port}/{database}",
      "defaultPort": 3306,
      "maven": {
        "groupId": "com.mysql",
        "artifactId": "mysql-connector-j",
        "version": "8.3.0"
      }
    }
  ]
}
```

字段说明：

- `id`: 驱动唯一标识
- `name`: 显示名称
- `driverClass`: JDBC 驱动类全限定名
- `urlTemplate`: JDBC URL 模板
- `defaultPort`: 默认端口
- `maven`: Maven 坐标（用于动态下载）

## Docker 部署

项目根目录提供 `Dockerfile`（三阶段构建：前端 npm build → 后端 maven package → JRE 运行镜像）与 `docker-compose.yml`：

```bash
# 直接构建镜像
docker build -t lyradb .

# 或使用 Compose（推荐）
docker compose up -d
```

Compose 关键配置：

| 项 | 值 | 说明 |
| ---- | ---- | ------ |
| 端口 | `8080:8080` | API 与内嵌前端 |
| 卷 `/app/data` | H2 数据库文件持久化 | |
| 卷 `/root/.lyradb` | 驱动 JAR 缓存持久化 | |
| `JASYPT_PASSWORD` | 必填，经 `.env` 注入 | 缺失时容器拒绝启动 |
| `LYRADB_EDITION` | 默认 `personal` | 可切换 `enterprise` |
| `LYRADB_DDL_AUTO` | 默认 `update` | |

`.dockerignore` 已排除 `node_modules/`、`target/`、`dist/` 等构建产物。

## 前端配置

### Vite 开发代理

```typescript
// vite.config.ts
server: {
  port: 5173,
  proxy: {
    '/api': {
      target: 'http://localhost:8080',
```

### 构建配置

- 目标: ES2020
- 输出: `frontend/dist/`
- 代码分割: monaco / element-plus / vxe-table 独立 chunk
- chunk 大小警告阈值: 1500KB

### 外观偏好持久化

外观设置存于浏览器 localStorage，`index.html` 内联脚本在 CSS 加载前预读应用（防暗色闪白）：

| 键 | 取值 | 说明 |
| ---- | ---- | ------ |
| `theme` | `light` / `dark` / `system` | 主题三态，`system` 跟随操作系统 |
| `accent` | `navy` / `emerald` / `amber` / `violet` | 强调色预设，映射 `data-accent` 属性 |
| `density` | `comfortable` / `compact` | 数据行密度，映射 `data-density` 属性（行高 32/24px） |

## 安全注意事项

1. **生产环境**必须修改 `LYRADB_EDITION=enterprise` 启用认证
2. **Jasypt 密钥**不要硬编码在配置文件中，通过环境变量注入
3. **H2 Console** 仅在开发环境开启
4. **CORS** 生产环境需配置实际域名白名单（默认仅放行 `localhost:5173`）
5. **企业版生产账号** `LYRADB_USER` / `LYRADB_PASSWORD` 必须经环境变量注入（无默认弱口令兜底）
