# API 接口概览

## 基础信息

- **Base URL**: `http://localhost:8080/api`
- **上下文路径**: `/api`（由 `server.servlet.context-path` 配置）
- **认证方式**: 企业版使用 Session Cookie（登录后自动携带）；个人版接口免认证

## 接口清单

### 应用信息 `/app`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/app/info` | 获取应用信息（edition、版本号） |

### 认证 `/auth`（企业版）

| 方法 | 路径 | 说明 |
| ------ | ------ | ------ |
| POST | `/auth/login` | 用户登录（username/password） |
| POST | `/auth/logout` | 用户登出 |
| GET | `/auth/me` | 获取当前登录用户信息 |
| POST | `/auth/workspace` | 切换当前工作区 |

### 连接管理 `/connections`

| 方法 | 路径 | 说明 |
| ------ | ------ | ------ |
| GET | `/connections` | 获取所有连接列表 |
| GET | `/connections/{id}` | 获取单个连接配置 |
| POST | `/connections` | 创建新连接 |
| PUT | `/connections/{id}` | 更新连接配置 |
| DELETE | `/connections/{id}` | 删除连接 |
| POST | `/connections/test` | 测试连接可用性（传配置，不落库） |
| POST | `/connections/{id}/connect` | 建立连接 |
| POST | `/connections/{id}/disconnect` | 断开连接 |
| GET | `/connections/{id}/status` | 查询连接状态 |
| POST | `/connections/{id}/favorite` | 切换连接收藏 |
| POST | `/connections/{id}/duplicate` | 复制连接 |
| POST | `/connections/export` | 导出连接配置（JSON，凭证脱敏） |
| POST | `/connections/import` | 导入连接配置（凭证重新加密） |

### SQL 查询 `/query`

| 方法 | 路径 | 说明 |
| ------ | ------ | ------ |
| POST | `/query/{connectionId}/execute` | 执行查询 SQL（body: `{sql, defaultDatabase?, force?}`；命中 SQL 审核拦截规则时响应含 `reviewBlocked/reviewFindings`，个人版可 `force=true` 强制执行） |
| POST | `/query/{connectionId}/update` | 执行更新/DDL 语句 |
| POST | `/query/{connectionId}/cancel` | 取消正在执行的查询（仅 JDBC 类驱动） |
| POST | `/query/{connectionId}/export` | 导出查询结果（CSV/JSON/SQL，Blob 下载） |
| POST | `/query/{connectionId}/import` | 批量导入行数据（body: `{schema?, table, rows}`） |
| POST | `/query/{connectionId}/import/file` | 文件上传导入（multipart：file、table、schema?、format?，CSV 首行表头 / JSON 数组） |

### 元数据 `/metadata`

| 方法 | 路径 | 说明 |
| ------ | ------ | ------ |
| GET | `/metadata/{connectionId}/tree` | 获取对象树（库→表→列） |
| GET | `/metadata/{connectionId}/columns` | 获取表列信息 |
| GET | `/metadata/{connectionId}/ddl` | 获取表 DDL |
| GET | `/metadata/{connectionId}/databases` | 获取数据库列表 |
| GET | `/metadata/{connectionId}/search` | 元数据对象搜索 |
| GET | `/metadata/{connectionId}/capabilities` | 查询驱动能力（只读/DML 支持等） |
| GET | `/metadata/{connectionId}/er` | 获取 ER 图数据 |

### 驱动管理 `/drivers`

| 方法 | 路径 | 说明 |
| ------ | ------ | ------ |
| GET | `/drivers` | 获取所有可用驱动列表 |
| GET | `/drivers/types` | 获取支持的数据库类型列表 |
| GET | `/drivers/{dbType}` | 获取指定类型驱动详情 |
| GET | `/drivers/{dbType}/status` | 查询驱动下载状态 |
| POST | `/drivers/{dbType}/download` | 下载指定驱动 |

### 查询历史 `/history`

| 方法 | 路径 | 说明 |
| ------ | ------ | ------ |
| GET | `/history` | 获取查询历史（可选 connectionId/favorite 过滤，最多 500 条） |
| GET | `/history/search` | 关键字全文搜索（SQL 文本、标题或标签） |
| POST | `/history/{id}/favorite` | 切换收藏 |
| PUT | `/history/{id}/tags` | 更新标签（逗号分隔，空串清空） |
| DELETE | `/history/{id}` | 删除单条历史 |
| DELETE | `/history` | 清空历史（可选 connectionId 限定范围） |

### 数据迁移 `/migration`

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/migration` | 执行跨库迁移 |

### AI 对话 `/ai`

| 方法 | 路径 | 说明 |
| ------ | ------ | ------ |
| GET | `/ai/presets` | 获取预置提示词 |
| GET | `/ai/providers` | 获取可用 AI 提供商 |
| POST | `/ai/chat` | AI 对话（自然语言转 SQL） |
| POST | `/ai/chat/stream` | AI 对话（SSE 流式返回） |

### 后台任务 `/tasks`

| 方法 | 路径 | 说明 |
| ------ | ------ | ------ |
| POST | `/tasks` | 提交长查询后台任务（body: `{connectionId, connectionName?, sql, defaultDatabase?, force?}`） |
| GET | `/tasks` | 获取任务列表（RUNNING/DONE/ERROR/CANCELLED） |
| GET | `/tasks/{id}/result` | 获取已完成任务的暂存结果集 |
| POST | `/tasks/{id}/cancel` | 取消运行中任务 |
| DELETE | `/tasks/{id}` | 移除任务记录（连带释放暂存结果） |

### 定时报表订阅 `/reports`

| 方法 | 路径 | 说明 |
| ------ | ------ | ------ |
| GET | `/reports` | 获取订阅列表 |
| POST | `/reports` | 创建/更新订阅（带 id 即更新；SQL 仅允许 SELECT/WITH） |
| DELETE | `/reports/{id}` | 删除订阅（连带执行记录） |
| GET | `/reports/{id}/runs` | 获取执行记录 |
| POST | `/reports/{id}/trigger` | 立即执行一次（含 Webhook 推送） |

## 企业版专用接口

### 管理后台 `/admin`（需管理员角色）

| 方法 | 路径 | 说明 |
| ------ | ------ | ------ |
| GET | `/admin/users` | 用户列表 |
| POST | `/admin/users` | 创建用户 |
| GET | `/admin/datasources` | 数据源列表 |
| GET | `/admin/datasources/{id}` | 数据源详情 |
| POST | `/admin/datasources` | 创建数据源 |
| PUT | `/admin/datasources/{id}` | 更新数据源 |
| DELETE | `/admin/datasources/{id}` | 删除数据源 |
| POST | `/admin/datasources/{id}/test` | 测试数据源连通性 |
| GET | `/admin/grants` | 授权列表 |
| POST | `/admin/grants` | 创建授权 |
| DELETE | `/admin/grants/{id}` | 删除授权 |
| GET | `/admin/ai/providers` | AI 提供商配置列表 |
| POST | `/admin/ai/providers` | 创建 AI 提供商配置 |
| POST | `/admin/ai/providers/{id}/default` | 设为默认提供商 |
| DELETE | `/admin/ai/providers/{id}` | 删除 AI 提供商配置 |
| GET | `/admin/approval-policy` | 获取审批策略 |
| PUT | `/admin/approval-policy` | 更新审批策略 |
| GET | `/admin/masking` | 数据脱敏规则列表 |
| POST | `/admin/masking` | 创建/更新脱敏规则（带 id 即更新） |
| DELETE | `/admin/masking/{id}` | 删除脱敏规则 |

### 审批 `/approvals`

| 方法 | 路径 | 说明 |
| ------ | ------ | ------ |
| POST | `/approvals` | 提交审批申请 |
| GET | `/approvals` | 获取审批列表 |
| GET | `/approvals/pending` | 获取待我审批列表 |
| POST | `/approvals/{id}/approve` | 审批通过 |
| POST | `/approvals/{id}/reject` | 审批拒绝 |
| POST | `/approvals/{id}/execute` | 执行已批准的申请 |
| DELETE | `/approvals/{id}` | 撤销/删除申请 |

### 审计 `/audit`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/audit/mine` | 查询本人操作记录 |
| GET | `/audit/workspace` | 查询工作区审计日志（需管理角色） |

### 企业查询与导出 `/ent`

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/ent/query` | 企业版 SQL 查询（含权限校验与审计记录） |
| POST | `/ent/export` | 企业版导出（需携带已批准的 approvalRequestId） |

### 授权 `/grants`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/grants/mine` | 获取当前用户被授权的数据源 |

## WebSocket 端点

| 路径 | 说明 |
|------|------|
| `/ws/drivers` | 驱动下载进度推送（原生 WebSocket，非 STOMP） |
| `/ws/tasks` | 后台任务状态广播（提交/完成/失败/取消事件） |
