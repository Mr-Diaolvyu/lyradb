# API 接口概览

## 基础信息

- **Base URL**: `http://localhost:8080/api`
- **上下文路径**: `/api`（由 `server.servlet.context-path` 配置）
- **认证方式**: 企业版使用 Session Cookie（登录后自动携带）；个人版接口免认证

## 接口清单

### 应用信息 `/app`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/app/info` | 获取应用信息（edition、版本号） |

### 认证 `/auth`（企业版）

| 方法 | 路径 | 说明 |
| ------ | ------ | ------ |
| GET | `/auth/csrf` | 获取 CSRF token、请求头名与参数名；登录及其他状态变更前调用 |

### SQL 查询 `/query`

| 方法 | 路径 | 说明 |
| ------ | ------ | ------ |
| POST | `/query/{connectionId}/execute` | 执行查询 SQL（body: `{sql, defaultDatabase?, force?}`；命中 SQL 审核拦截规则时响应含 `reviewBlocked/reviewFindings`，个人版可 `force=true` 强制执行） |
| POST | `/query/{connectionId}/update` | 执行更新/DDL 语句 |
| POST | `/query/{connectionId}/cancel` | 取消正在执行的查询（仅 JDBC 类驱动） |
| POST | `/query/{connectionId}/export` | 导出查询结果（CSV/JSON/SQL，Blob 下载） |
| POST | `/query/{connectionId}/import` | 批量导入行数据（body: `{schema?, table, rows}`） |
| POST | `/query/{connectionId}/import/file` | 文件上传导入（multipart：file、table、schema?、format?，CSV 首行表头 / JSON 数组） |

|------|------|------|

### AI 对话 `/ai`

| 方法 | 路径 | 说明 |
| ------ | ------ | ------ |
| GET | `/ai/presets` | 获取预置提示词 |
| GET | `/ai/providers` | 获取可用 AI 提供商 |
| POST | `/ai/chat` | AI 对话（自然语言转 SQL）；企业版仅在 body 显式传入 `attachMetadata=true` 与 `metadataSnapshotId` 时一次性附加快照 |
| POST | `/ai/metadata/snapshots` | 企业版显式采集授权范围内的数据库结构；body: `{grantedSourceName,database?,schemas?,tables?}`，不读取业务数据行 |
| GET | `/ai/metadata/snapshots/{id}/download?format=json|markdown` | 下载当前用户在当前工作空间创建且仍有效的元数据快照 |
| POST | `/ai/chat/stream` | AI 对话（SSE 流式返回） |

企业版元数据采集请求必须在 `database`、`schemas`、`tables` 中至少指定一项范围。快照响应为 `{id,grantedSourceName,database,schemas,tables,databaseCount,schemaCount,tableCount,columnCount,approximateTokens,preview,expiresAt}`，其中 `preview` 是 `{database,schema,table,type,columns[]}` 数组。快照绑定创建人、工作空间、授权与安全指纹，默认 30 分钟过期；AI 附加会再次校验并一次性消费。未显式附加时，企业 AI 不会自动抓取数据库元数据。

#### v3.1.0 连接配置迁移安全契约

- `credentialMode` 仅支持 `OMIT`、`PASSWORD_ENCRYPTED`、`PLAINTEXT`。明文模式在申请阶段和下载阶段都必须显式确认风险；加密密码只在批准后的下载请求或导入预览请求中短暂传递，不进入审批记录。
- 导入预览响应只返回 `parameterKeys`、`credentialKeys`、`credentialsIncluded` 等掩码元信息，不回显真实凭据。`previewToken` 绑定用户与工作空间、10 分钟过期且只能消费一次。
- 导入决策 `action` 支持 `SKIP`、`RENAME`、`OVERWRITE`；`RENAME` 必须提供 `newDisplayName`。无冲突时 `OVERWRITE` 表示直接创建，发生冲突时表示覆盖当前工作空间内同显示名数据源。
- `DATASOURCE_EXPORT` 批准窗口为 15 分钟，下载时重新校验申请人、工作空间和数据源安全指纹，并以原子方式消费审批。

### 审批 `/approvals`

| 方法 | 路径 | 说明 |
| ------ | ------ | ------ |
| POST | `/approvals` | 提交通用 SQL 审批申请（仅 `EXPORT`、`DANGEROUS_SQL`）；审批域另支持由 `/admin/datasources/export-requests` 创建的 `DATASOURCE_EXPORT` |
| GET | `/approvals` | 获取审批列表 |
| GET | `/approvals/pending` | 获取待我审批列表 |
| GET | `/approvals/{id}` | 获取审批详情及当前授权用户可见的不可变审批载荷 |
| POST | `/approvals/{id}/approve` | 审批通过 |
| POST | `/approvals/{id}/reject` | 审批拒绝 |
| DELETE | `/approvals/{id}` | 申请人撤销未执行申请 |

### 审计 `/audit`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/audit/mine` | 查询本人操作记录 |
| GET | `/audit/workspace` | 查询工作区审计日志（需管理角色） |

### 企业查询与导出 `/ent`

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/ent/query` | 企业版 SQL 查询（含权限校验与审计记录） |
| POST | `/ent/export?approvalRequestId={id}` | 一次性企业导出；body 仅含审批绑定的 `{sql,format,defaultDatabase}`，逻辑数据源由审批记录派生 |

企业导出会再次校验申请人、工作空间、授权、SQL、格式和默认数据库，并以原子方式领取审批；同一审批不能重复导出，客户端也不能通过请求体替换逻辑数据源。

### 授权 `/grants`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/grants/mine` | 获取当前用户被授权的数据源 |
