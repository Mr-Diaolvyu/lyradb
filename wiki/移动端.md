# 移动端说明

## 概述

移动端采用**瘦客户端**架构，不直连数据库，所有数据操作经企业版后端 API 完成。当前提供 Android 参考骨架（Kotlin + Jetpack Compose），鸿蒙 NEXT 版本规划中。

## 架构设计

```
┌─────────────────────────────┐
│     Android / 鸿蒙 客户端    │
│  (Jetpack Compose / ArkUI)  │
├─────────────────────────────┤
│  Retrofit / @ohos.net.http  │
│  (HTTP + Session Cookie)    │
└──────────────┬──────────────┘
               │ HTTP
               ▼
┌─────────────────────────────┐
│   企业版后端 /api/*          │
│   (Spring Boot, 端口 8080)  │
└─────────────────────────────┘
```

## 功能范围（MVP）

| 功能 | 说明 |
|------|------|
| 登录 | 企业版用户认证（Session） |
| 我的数据源 | 查看被授权的逻辑数据源（无连接信息） |
| AI 对话查数据 | 自然语言查询，复用 `/ai/chat` |
| 审批中心 | 移动端审批（通过/拒绝） |
| 操作审计 | 查看本人操作记录 |

**不上移动端的功能**：SQL 编辑器、数据导入导出、ER 图、数据迁移、连接管理。

## 复用后端接口

| 接口 | 用途 |
|------|------|
| `POST /auth/login` | 登录 |
| `GET /grants/mine` | 我的数据源 |
| `POST /ent/query` | 企业查询 |
| `POST /ai/chat` | AI 对话 |
| `GET/POST /approvals` | 审批操作 |
| `GET /audit/mine` | 我的审计记录 |
| `GET /app/info` | 应用信息 |

## 开发说明

### 后端地址配置

- **模拟器**: `http://10.0.2.2:8080/api`（Android 模拟器访问宿主机）
- **真机**: 改为后端实际 IP，需 HTTPS 或在 Manifest 允许明文 HTTP

### 导入步骤

1. Android Studio → Open → 选择 `mobile/android` 目录
2. Sync Gradle（下载 Compose/Retrofit/OkHttp 依赖）
3. 运行到模拟器/真机
4. 使用 `admin/admin` 登录（企业版后端需先启动）

### 技术栈

| 组件 | 技术 |
|------|------|
| UI | Jetpack Compose + Material 3 |
| 网络 | Retrofit 2 + OkHttp 4 |
| 异步 | Kotlin Coroutines |
| 架构 | MVVM（ViewModel + State） |
| 会话 | CookieJar 持久化 Session |

## 鸿蒙 NEXT 规划

| 对应关系 | Android | 鸿蒙 |
|----------|---------|------|
| UI 框架 | Jetpack Compose | ArkUI |
| 网络库 | OkHttp/Retrofit | @ohos.net.http |
| 安全存储 | Android Keystore | HUKS |
| 开发工具 | Android Studio | DevEco Studio |
| 语言 | Kotlin | ArkTS |

接口契约与 Android 版保持一致，详见 `product-discovery/移动端APP规划.md`。
