# 移动端说明

## 概述

移动端属于**本地客户端形态**的一员，采用 **BS 封装客户端**架构：以原生外壳（Android / 鸿蒙 NEXT / iOS）承载启动、生物识别、系统集成等原生体验，内部通过 WebView 加载 BS 架构版本的前端页面。移动端**不直连数据库、不承载 JDBC 驱动**，所有数据操作由其连接的 **BS 服务端**完成。

移动端可连接两类服务端：

- **个人自托管 BS 服务**：用户自己部署（本机 Docker / 家庭服务器 / 小云主机）的 LyraDB 服务，`edition=personal`，凭据归用户自己、无管理员与租户。
- **企业 BS 服务**：团队部署的 LyraDB 服务，`edition=enterprise`，受 RBAC / 审批 / 审计治理。

> 一个 App 覆盖两种场景：启动时填写服务端地址即可，个人与企业共用同一份前端与后端内核。

## 架构设计

```
┌───────────────────────────────────────────┐
│     Android / 鸿蒙 NEXT / iOS 原生外壳      │
│  (Kotlin+AppCompat / ArkTS+ArkUI / SwiftUI) │
│  · 启动/生物识别/推送/系统集成               │
│  · 安全存储服务端地址与会话                  │
├───────────────────────────────────────────┤
│   WebView（Android WebView / ArkWeb / WKWebView）│
│         加载 BS 前端（Vue 3 + Vite）        │
└───────────────────────┬───────────────────┘
                        │ HTTPS / WSS
                        ▼
┌───────────────────────────────────────────┐
│   BS 服务端 /api/*（Spring Boot）           │
│   个人自托管（personal） 或 企业（enterprise）│
├───────────────────────────────────────────┤
│   Controller → Service → Repository         │
│   JDBC 动态驱动 → 目标数据库（9 库全支持）   │
└───────────────────────────────────────────┘
```

## 功能范围

移动端 UI 完全复用 BS 前端，功能随所连服务端的 edition 而定，与 BS 版本保持一致：

| 功能 | 个人自托管服务 | 企业服务 |
| ------ | ---------------- | ---------- |
| 连接管理 | 用户自建/管理连接 | 使用被授权数据源 |
| SQL 查询 | ✓ | ✓（受权限） |
| AI 对话查数据 | ✓（用户自配 KEY） | ✓（企业托管 KEY） |
| ER 图浏览 | ✓ | ✓ |
| 数据导出 | 二次确认 + 本地留痕 | 审批流 |
| 审批中心 | — | ✓（移动审批亮点） |
| 操作审计 | 本人记录 | 本人记录 |

> 由于前端复用 BS 页面，移动端天然支持全部 9 种数据库（连接由服务端完成），不再受手机无法运行 JDBC 驱动的限制。触屏适配通过前端响应式布局实现。

## 原生外壳职责

原生外壳只做 WebView 无法胜任的部分，保持轻薄：

| 职责 | 说明 |
| ------ | ------ |
| 服务端地址管理 | 添加/切换个人或企业服务端地址，加密存储（鸿蒙端提供顶栏切换入口，iOS 端支持清除 WebView 缓存） |
| 会话与安全 | 生物识别快速解锁（三端已落地：Android BiometricPrompt / 鸿蒙 userAuth / iOS LocalAuthentication，可在配置页开关）；会话令牌存 Keystore / HUKS / Keychain |
| WebView 容器 | 加载并托管 BS 前端，注入原生桥接能力 |
| 系统集成 | 推送通知（如审批提醒）、分享、深链 |
| 网络策略 | HTTPS only；证书校验；离线态提示 |

## 开发说明

### 服务端地址配置

- **模拟器**: `http://10.0.2.2:8080`（Android 模拟器访问宿主机 BS 服务）
- **真机**: 填写 BS 服务实际地址，生产环境要求 HTTPS

### 导入步骤

1. Android Studio → Open → 选择 `mobile/android` 目录
2. Sync Gradle（下载 WebView / 安全存储相关依赖）
3. 运行到模拟器/真机
4. 首次启动填写 BS 服务端地址（个人自托管或企业），加载前端后使用

### 技术栈

| 组件 | 技术 |
| ------ | ------ |
| 外壳 UI | AppCompat View + Material 3 |
| Web 容器 | Android WebView（WebKit 增强） |
| 前端 | 复用 BS 版本 Vue 3 前端 |
| 安全存储 | Android Keystore |
| 语言 | Kotlin |

## 三端外壳对应关系

| 对应关系 | Android | 鸿蒙 NEXT | iOS |
| ---------- | --------- | ----------- | ----- |
| 外壳语言 | Kotlin | ArkTS | Swift |
| 外壳 UI | AppCompat View | ArkUI | SwiftUI |
| Web 容器 | Android WebView | ArkWeb（Web 组件） | WKWebView |
| 安全存储 | Android Keystore | HUKS | Keychain |
| 生物识别 | BiometricPrompt | @ohos.userIAM.userAuth | LocalAuthentication（FaceID/TouchID） |
| 开发工具 | Android Studio | DevEco Studio | Xcode |

> 三端外壳各自实现，但**复用同一套 BS 前端与后端内核**；仅原生桥接与安全存储需分别适配。详见 `product-discovery/移动端APP规划.md`。
