# 前端模块说明

## 概述

前端基于 Vue 3.4 + TypeScript + Vite 5 构建，使用 Element Plus 作为 UI 组件库，Monaco Editor 作为 SQL 编辑器，VXE Table 展示数据表格，Pinia 管理全局状态。

## 核心组件说明

### SQL 编辑器 (SqlEditor.vue)

- 基于 Monaco Editor，支持多数据库方言语法高亮
- 多标签页编辑，支持 Ctrl+Enter 执行
- 自动补全（表名/列名）

### 数据表格 (DataTable.vue)

- 基于 VXE Table，支持虚拟滚动（大数据量）
- 列排序、列宽调整、单元格复制

### ER 图 (ErDiagramView.vue)

- 基于 Vue Flow，自动布局表关系图
- 展示表间外键关系

### 导航树 (NavTree.vue)

- 树形展示：连接 → 数据库 → 表 → 列
- 右键菜单（查询/导出/查看结构）

## 状态管理

| Store | 核心状态 | 说明 |
|-------|----------|------|
| `auth` | user, edition, isAuthenticated, isAdmin | 认证与版本判断 |
| `connection` | connections, activeConnection | 连接列表与当前连接 |
| `editor` | tabs, activeTab, sqlContent | 编辑器标签页管理 |
| `history` | records | 查询历史列表 |
| `theme` | isDark | 亮暗主题切换 |
| `ui` | panelStates | 面板展开/折叠状态 |

## 路由设计

- 使用 Hash 模式（`createWebHashHistory`），兼容桌面打包 file:// 协议
- 企业版路由守卫：未登录跳转 `/login`，管理员页面校验角色
- 个人版：无路由守卫，直接展示 MainView

## 构建配置

- **开发代理**：`/api` → `http://localhost:8080`（含 WebSocket）
- **代码分割**：monaco / element-plus / vxe-table 独立 chunk
- **构建目标**：ES2020
- **输出目录**：`frontend/dist/`
