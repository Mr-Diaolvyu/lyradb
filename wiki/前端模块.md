# 前端模块说明

> 产品定位：企业前端是 [LyraDB · 天琴智库](../docs/product/产品定位.md) 的团队智库控制面，技术事实仍以本文为准。

## 概述

前端基于 Vue 3.4 + TypeScript + Vite 5 构建，使用 Element Plus 作为 UI 组件库，Monaco Editor 作为 SQL 编辑器，VXE Table 展示数据表格，Pinia 管理全局状态，vue-i18n 提供中英文国际化。

## 核心组件说明

### SQL 编辑器 (SqlEditor.vue)

- 基于 Monaco Editor，支持多数据库方言语法高亮
- 多标签页编辑，支持 Ctrl+Enter 执行
- 自动补全（表名/列名）

### 数据表格 (DataTable.vue)

- 基于 VXE Table，支持虚拟滚动（大数据量）
- 列排序、列宽调整、单元格复制
- 列类型推断（数值/布尔/日期/JSON/文本），表头类型徽标，数值列右对齐，NULL 灰显斜体
- 表头一键切换字段名 ⇄ 字段注释（懒加载列注释，仅单表查询）
- 行高跟随密度偏好（舒适 32px / 紧凑 24px）
<!-- last-updated: 2026-07-30 -->

### ER 图 (ErDiagramView.vue)

- 基于 Vue Flow，自动布局表关系图
- 展示表间外键关系

### 导航树 (NavTree.vue)

- 树形展示：连接 → 数据库 → 表 → 列
- 右键菜单（查询/导出/查看结构）
- 节点图标为线性 SVG（NavIcon.vue，1.4px 描边，含暗色半透明底适配）
<!-- last-updated: 2026-07-30 -->

### 条件过滤器 (FilterBar.vue)

- 挂载于 SQL 编辑区与结果面板之间，折叠式条件栏
- 8 种操作符（=/<>/LIKE/>/</BETWEEN/IS NULL/IS NOT NULL），AND/OR 组合，WHERE 子句实时预览
- 应用时以原 SQL 为子查询包装过滤，可一键清除还原
<!-- last-updated: 2026-07-30 -->

### 命令面板 (CommandPalette.vue)

- 全局 Ctrl/Cmd+K 唤起，前缀路由：`>` 命令、`#` 表、`@` 连接，无前缀全部四组
- 远程搜索 200ms 防抖（表名搜索 + 历史全文搜索），↑↓/Enter/Esc 键盘导航

### 图表视图 (ChartView.vue)

- 纯 SVG 自绘柱状/折线/饼图，无图表库依赖，挂载于底部面板“图表”Tab
- 自动推断数值列（非空值 80% 可转数字）并推荐图表类型，最多取前 50 个数据点

## v3.1.0 企业连接迁移与 AI 元数据

### 管理后台 (AdminView.vue)

- 数据源表支持多选并提交 `DATASOURCE_EXPORT` 审批申请，凭据模式为不含凭据、密码加密或明文。
- 明文模式在申请时执行复选确认和二次风险弹窗；加密密码不进入申请表单，只在审批通过后的下载阶段询问。
- 导入先上传配置包并生成一次性预览，页面只展示参数键、凭据键、是否含凭据和冲突信息，不回显真实凭据。
- 每条连接可选择跳过、重命名或覆盖；无冲突连接的“直接导入”使用后端 `OVERWRITE` 创建语义。解析过程支持取消，客户端同时拦截超过 10 MiB 的文件。

### 审批中心 (ApprovalsView.vue)

- 识别 `DATASOURCE_EXPORT` 并展示连接数量、凭据模式和明文风险标签；现有查询结果 `EXPORT` 流程保持不变。
- 审批通过后才允许申请人下载一次：密码加密包在此时临时输入密码，明文包再次弹出风险确认并发送 `plaintextRiskConfirmed=true`。
- 列表按当前权限补载审批详情，用不可变 `payloadJson` 决定下载交互，客户端不能自行替换凭据模式或数据源集合。

### AI 数据助手 (AiChatView.vue)

- 元数据不会随聊天自动抓取。用户选择授权数据源，并至少指定数据库、Schema 或表范围后，点击“采集元数据”才调用快照接口。
- 采集支持取消、结构化表/列预览、近似 Token 数展示，以及 JSON/Markdown 文档下载；不展示或读取业务数据行。
- “仅下一条消息附加”是显式的一次性开关；发送后立即复位，由服务端再次校验并消费快照。
- Schema/表候选来自当前授权 allowlist，同时保留手动输入；所有加载、错误、取消和空状态都有可见反馈。

### 类型化 API (`api/ent.ts`)

- 连接导出：`adminRequestDataSourceExport`、`adminDownloadDataSourceExport`。
- 连接导入：`adminPreviewDataSourceImport`、`adminApplyDataSourceImport`。
- 元数据快照：`createMetadataSnapshot`、`downloadMetadataSnapshot`；`aiChat` 显式接收 `attachMetadata` 与 `metadataSnapshotId`。
- `utils/enterpriseTransfer.ts` 集中校验审批载荷、构造冲突决策、规范化元数据范围并安全格式化结构预览。

## v3.1.1 Excel 连接导入体验

- 企业管理后台在“导入连接”旁提供可见的“下载 Excel 模板”入口，下载文件名固定为 `LyraDB-连接导入模板.xlsx`。
- 文件选择器接受 `.xlsx`、`.json`、`.lyradb`；选择 Excel 时自动禁用仅适用于加密 JSON 包的密码输入框，并继续执行 10 MiB 客户端上限。
- `utils/enterpriseTransfer.ts` 集中维护模板文件名、允许的导入扩展名和 Excel 类型判断，配套 Vitest 覆盖大小写扩展名与密码框判断。
- `api/ent.ts` 新增 `adminDownloadDataSourceImportTemplate`；模板下载失败、文件类型错误和解析错误均提供明确反馈。

## 路由设计

- 使用 Hash 模式（`createWebHashHistory`），兼容桌面打包 file:// 协议
- 企业版路由守卫：未登录跳转 `/login`，管理员页面校验角色
- 个人版：无路由守卫，直接展示 MainView

## 国际化（i18n）

- vue-i18n@9 组合式 API（`legacy: false`），语言包：简体中文（默认）/ English
- 语言持久化于 localStorage（键 `lyradb_locale`），未设置时按浏览器语言探测
- 顶部导航栏提供语言切换下拉；Element Plus 组件语言经 `App.vue` 的 `el-config-provider` 联动切换
