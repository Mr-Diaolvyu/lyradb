# 后端模块说明

## 概述

后端基于 Spring Boot 3.2.5（Java 17），采用经典 Controller → Service → Repository 三层架构，内嵌 H2 数据库存储应用配置数据（连接信息、用户、审计日志等）。

## 包结构

```
io.github.lexaquila.lyradb/
├── config/          # 配置与启动
├── controller/      # REST 控制器
├── driver/          # JDBC 驱动管理
├── model/
│   ├── dto/         # 数据传输对象
│   └── entity/      # JPA 实体
├── repository/      # Spring Data JPA 仓库
├── service/         # 业务服务
└── LyraDbApplication.java  # 启动入口
```

## 配置层 (config/)

| 类 | 职责 |
| ---- | ------ |
| `AppProperties` | 自定义配置绑定（edition、driver-cache-dir、query-timeout 等） |
| `SecurityConfig` | Spring Security 配置，按 edition 门控认证策略 |
| `SecurityProperties` | 安全相关配置属性 |
| `DbUserDetailsService` | 从 H2 加载用户信息供 Security 认证 |
| `CorsConfig` | 跨域配置（开发环境允许 localhost:5173） |
| `WebSocketConfig` | WebSocket 端点注册（/ws/drivers 驱动下载进度、/ws/tasks 后台任务通知） |
| `EnterpriseBootstrap` | 企业版启动引导（初始化管理员、默认审批策略） |
| `DesktopTrayConfig` | 桌面版系统托盘（仅 `app.desktop.tray-enabled=true` 时启用，jpackage 注入） |
| `DesktopAccessGuardFilter` | 一次性 bootstrap 交换、Session 绑定 proof、API/WS 本机门禁与精确 Origin 校验 |
| `StaticResourceConfig` / `FrontendSecurityHeadersFilter` | 根静态 Context、dist 白名单、临时目录清理、CSP 与浏览器安全响应头 |
| `GlobalExceptionHandler` | 全局异常处理（@RestControllerAdvice） |

## 服务层 (service/)

| 服务 | 职责 |

| `ConnectionService` | 连接管理核心（创建/测试/JDBC连接池/SSH隧道集成） |

| `MigrationService` | 跨库数据迁移（结构+数据） |
| `ImportService` | 数据导入（CSV/JSON 行数据与 multipart 文件上传，批量 INSERT） |
| `SshTunnelService` | SSH 隧道管理（MINA SSHD） |
| `AiProviderService` | AI 提供商配置管理 |
| `EnterpriseAiService` | 企业版 AI 对话（NL2SQL） |
| `EnterpriseQueryService` | 企业版查询（权限校验+审计） |
| `DataSourceService` | 企业版数据源管理 |
| `GrantService` | 数据源授权管理 |
| `ApprovalService` | 审批工作流 |
| `ApprovalExpirationScheduler` | 审批超时自动过期 |
| `AuditService` | 审计日志记录与查询 |
| `UserService` | 用户 CRUD |
| `SecurityUtil` | 安全工具（获取当前用户等） |

| `TaskWebSocketHandler` | /ws/tasks 任务状态广播 |
| `MaskingService` | 结果集脱敏（按规则匹配表/列，FULL/PARTIAL/HASH 三种方式，企业版） |
| `ReportScheduleService` | 定时报表订阅（HOURLY/DAILY/WEEKLY 调度、Webhook 推送、执行记录） |

## 驱动管理模块 (driver/)

负责 JDBC 驱动的全生命周期管理：

- 解析 `drivers.json` 驱动注册表
- 通过 Maven Resolver 从远程仓库下载驱动 JAR
- 本地缓存管理（`~/.lyradb/drivers/`）
- 自定义 URLClassLoader 隔离加载驱动类
- WebSocket 实时推送下载进度

## 持久化

- 使用内嵌 H2 文件数据库；路径由 profile 决定（开发默认 `backend/data/lyradb`，桌面为用户目录，容器为 `/app/data/lyradb`）
- 数据结构只通过 `db/migration/` 下的 Flyway 脚本演进，Hibernate 在所有 profile 中执行 `validate`
- 所有 Repository 继承 `JpaRepository`，部分含自定义查询方法
