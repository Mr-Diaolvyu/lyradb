# 后端模块说明

## 概述

`backend` 是企业 B/S 服务端，基于 Spring Boot 3.2.5（Java 17），采用 Controller → Service → Repository 分层，并以内嵌 H2 保存企业配置、用户和审计数据。个人原生桌面位于 `desktop`，不会启动本后端。

## 包结构

```
io.github.lexaquila.lyradb/
├── config/          # 配置与启动
├── controller/      # REST 控制器
├── driver/          # 企业驱动下载进度的 WebSocket 适配；共享驱动位于 core
├── model/
│   ├── dto/         # 数据传输对象
│   └── entity/      # JPA 实体
├── repository/      # Spring Data JPA 仓库
├── service/         # 业务服务
└── LyraDbApplication.java  # 启动入口
```

## 配置层 (config/)

| 类 | 职责 |
| ---- | ------ |
| `AppProperties` | 自定义配置绑定（edition、driver-cache-dir、query-timeout 等） |
| `SecurityConfig` | Spring Security 配置，按 edition 门控认证策略 |
| `SecurityProperties` | 安全相关配置属性 |
| `DbUserDetailsService` | 从 H2 加载用户信息供 Security 认证 |
| `CorsConfig` | 跨域配置（开发环境允许 localhost:5173） |
| `WebSocketConfig` | WebSocket 端点注册（/ws/drivers 驱动下载进度、/ws/tasks 后台任务通知） |
| `EnterpriseBootstrap` | 企业版启动引导（初始化管理员、默认审批策略） |
| `DesktopTrayConfig` / `DesktopAccessGuardFilter` | 旧 B/S 桌面包装兼容代码；发布 profile 已禁用，不进入个人原生桌面产物 |
| `DesktopAccessGuardFilter` | 一次性 bootstrap 交换、Session 绑定 proof、API/WS 本机门禁与精确 Origin 校验 |
| `StaticResourceConfig` / `FrontendSecurityHeadersFilter` | 根静态 Context、dist 白名单、临时目录清理、CSP 与浏览器安全响应头 |
| `GlobalExceptionHandler` | 全局异常处理（@RestControllerAdvice） |

## v3.1.0 共享连接包与元数据模型

企业连接迁移与元数据快照复用 `core`，避免个人桌面与企业后端出现不兼容格式：

- `core/transfer/connection`：连接包上限、三种凭据策略、PBKDF2-HMAC-SHA256 + AES-256-GCM 加密封装、风险码和结构校验。AI Key 与主密钥禁止进入连接包。
- `core/metadata/snapshot`：不含业务数据行的数据库/Schema/表/列快照、确定性 JSON/Markdown 渲染和近似 Token 估算。
- 企业导入预览只对外返回键名与冲突元信息，真实解密结果保存在短生命周期有界内存中；应用时原子消费预览令牌。
- 企业元数据采集要求 `database`、`schemas`、`tables` 至少提供一项，并在采集、下载、AI 附加三个阶段重新验证用户、工作空间、授权与安全指纹。

## 共享驱动管理模块 (`core/driver`)

负责 JDBC 驱动的全生命周期管理：

- 解析 `drivers.json` 驱动注册表
- 通过 Maven Resolver 从远程仓库下载驱动 JAR
- 本地缓存管理（`~/.lyradb/drivers/`）
- 自定义 URLClassLoader 隔离加载驱动类
- WebSocket 实时推送下载进度

## 持久化

- 企业后端使用内嵌 H2 文件数据库；开发默认 `backend/data/lyradb`，容器为 `/app/data/lyradb`。个人原生桌面不使用该 H2 元数据库。
- 数据结构只通过 `db/migration/` 下的 Flyway 脚本演进，Hibernate 在所有 profile 中执行 `validate`
- v3.1.0 的 `V2__enterprise_transfer_and_metadata.sql` 扩展审批操作类型长度并增加工作空间无授权审批索引，兼容 `DATASOURCE_EXPORT`
- 所有 Repository 继承 `JpaRepository`，部分含自定义查询方法
