# LyraDB 天琴智库 - 项目 Wiki

## 项目简介

LyraDB（天琴智库）是一款轻量、AI 驱动的通用数据库管理工具，支持多种数据库的连接管理、SQL 查询、数据导入导出、ER 图生成、AI 辅助查询等功能。项目采用前后端分离架构，提供**个人版**（桌面单用户）和**企业版**（多用户 RBAC 权限管控）两种发行模式。

## 核心特性

| 特性 | 说明 |
|------|------|
| 多数据库支持 | MySQL、PostgreSQL、Oracle、SQL Server、ClickHouse、SQLite 等，驱动动态下载 |
| SQL 编辑器 | 基于 Monaco Editor，支持语法高亮、自动补全、多标签页 |
| 数据导入导出 | 支持 CSV / Excel / SQL 格式导入导出 |
| ER 图 | 自动生成数据库实体关系图（Vue Flow） |
| AI 辅助查询 | 自然语言转 SQL，支持多 AI 提供商配置 |
| SSH 隧道 | 支持跳板机端口转发连接内网数据库 |
| 企业版 RBAC | 用户管理、数据源授权、审批工作流、操作审计 |
| 移动端 | Android 瘦客户端（Jetpack Compose），复用后端 API |
| 桌面打包 | jpackage 生成 app-image / MSI 安装包 |

## 技术栈概览

### 后端

- **框架**: Spring Boot 3.2.5 (Java 17)
- **持久化**: Spring Data JPA + H2（内嵌存储连接配置）
- **安全**: Spring Security（企业版 BCrypt + Session）
- **加密**: Jasypt（凭据加密存储）
- **驱动管理**: Maven Resolver（动态下载 JDBC 驱动）
- **SSH**: Apache MINA SSHD（隧道/跳板机）
<!-- last-updated: 2026-07-24 -->

### 前端

- **框架**: Vue 3.4 + TypeScript
- **构建**: Vite 5
- **UI 库**: Element Plus 2.7
- **编辑器**: Monaco Editor 0.47
- **表格**: VXE Table 4.6
- **状态管理**: Pinia 2
- **路由**: Vue Router 4（Hash 模式）
- **ER 图**: Vue Flow

### 移动端

- **平台**: Android（Kotlin + Jetpack Compose）
- **网络**: Retrofit + OkHttp
- **架构**: 瘦客户端，所有数据经后端 API

## 项目结构

```
lyradb/
├── backend/          # Spring Boot 后端
│   ├── src/main/java/io/github/lexaquila/lyradb/
│   │   ├── config/       # 配置类（安全、CORS、WebSocket、启动引导）
│   │   ├── controller/   # REST 控制器（21个）
│   │   ├── driver/       # 驱动管理模块
│   │   ├── model/        # 实体 & DTO
│   │   ├── repository/   # JPA 仓库
│   │   └── service/      # 业务服务层（18个）
│   └── src/main/resources/
│       ├── application.yml       # 公共配置
│       ├── application-dev.yml   # 开发环境
│       ├── application-prod.yml  # 生产环境
│       └── drivers.json          # 驱动注册表
├── frontend/         # Vue 3 前端
│   └── src/
│       ├── api/          # API 调用层
│       ├── components/   # 组件（编辑器/布局/导航/连接）
│       ├── layouts/      # 企业版布局
│       ├── router/       # 路由配置
│       ├── stores/       # Pinia 状态
│       ├── styles/       # 全局样式 & Design Token
│       ├── types/        # TypeScript 类型
│       ├── utils/        # 工具函数
│       └── views/        # 页面视图
├── mobile/android/   # Android 移动端骨架
├── product-discovery/ # 产品发现文档
└── wiki/             # 本 Wiki 文档
```

## 发行版说明

| 版本 | 环境变量 | 说明 |
|------|----------|------|
| 个人版 | `LYRADB_EDITION=personal`（默认） | 无认证，单用户桌面体验 |
| 企业版 | `LYRADB_EDITION=enterprise` | 多用户登录、RBAC、审批、审计 |
