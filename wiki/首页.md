# LyraDB 天琴智库 - 项目 Wiki

## 项目简介

LyraDB（天琴智库）是一款轻量、AI 驱动的通用数据库管理工具，支持多种数据库的连接管理、SQL 查询、数据导入导出、ER 图生成、AI 辅助查询等功能。产品分为两大形态，共享同一套前后端内核：**BS 架构版本**（浏览器访问，含 personal / enterprise 两种 edition）与**本地客户端版本**（桌面自带本地服务端直连；移动端为原生外壳 + WebView 封装 BS 前端，连接远端服务端）。

## 核心特性

| 特性 | 说明 |
| ------ | ------ |
| 多数据库支持 | MySQL、PostgreSQL、Oracle、SQL Server、ClickHouse、SQLite 等，驱动动态下载 |
| SQL 编辑器 | 基于 Monaco Editor，支持语法高亮、自动补全、多标签页 |
| 数据导入导出 | 支持 CSV / JSON 导入与 CSV / JSON / SQL 导出 |
| ER 图 | 自动生成数据库实体关系图（Vue Flow） |
| AI 辅助查询 | 自然语言转 SQL，支持多 AI 提供商配置 |
| SSH 隧道 | 支持跳板机端口转发连接内网数据库 |
| 企业版 RBAC | 用户管理、数据源授权、审批工作流、操作审计 |
| 移动端 | Android / 鸿蒙 NEXT / iOS 客户端（原生外壳 + WebView 封装 BS 前端） |
| 桌面客户端 | jpackage 生成 app-image 便携包（内嵌本地服务端） |

## 技术栈概览

### 后端

- **框架**: Spring Boot 3.2.5 (Java 17)
- **持久化**: Spring Data JPA + H2（内嵌存储连接配置）
- **安全**: Spring Security（企业版 BCrypt + Session）
- **加密**: AES-256-GCM（兼容读取历史 Jasypt 密文）
- **驱动管理**: Maven Resolver（动态下载 JDBC 驱动）
- **SSH**: Apache MINA SSHD（隧道/跳板机）
<!-- last-updated: 2026-07-28 -->

### 前端

- **框架**: Vue 3.4 + TypeScript
- **构建**: Vite 5
- **UI 库**: Element Plus 2.7
- **编辑器**: Monaco Editor 0.47
- **表格**: VXE Table 4.6
- **状态管理**: Pinia 2
- **路由**: Vue Router 4（Hash 模式）
- **国际化**: vue-i18n 9（中/英）
- **ER 图**: Vue Flow

### 移动端

- **平台**: Android（Kotlin）/ 鸿蒙 NEXT（ArkTS）/ iOS（Swift）
- **架构**: BS 封装客户端——原生外壳 + WebView 加载 BS 前端
- **服务端**: 连接个人自托管或企业 BS 服务，不直连数据库

## 发行版与形态说明

产品分为两大**形态**（访问方式），正交互两种 **edition**（环境变量 `LYRADB_EDITION` 控制）：

| 形态 | 载体 | edition | 说明 |
| ------ | ------ | --------- | ------ |
| BS 架构版本 | 浏览器 + 独立部署服务端 | personal / enterprise | 个人自用或团队协作 |
| 本地客户端·桌面 | jpackage 安装包（内嵌本地服务端） | personal | 无认证、单用户、本地直连、可离线 |
| 本地客户端·移动 | Android/鸿蒙/iOS 外壳 + WebView | 随所连服务端 | 连个人自托管或企业 BS 服务 |

> edition 决定能力（是否启用登录/RBAC/审批/审计），形态决定访问方式（浏览器/桌面安装包/移动 App），两者正交。
