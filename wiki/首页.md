# LyraDB 天琴智库 - 项目 Wiki

## 产品定位

LyraDB 是面向数据库开发、数据分析与企业治理的 AI 数据库工作台，支持 MySQL、PostgreSQL、Oracle、SQL Server、SQLite、ClickHouse、MaxCompute、MongoDB 和 Redis。

从 `3.0.1` 起，产品明确拆分为两种架构：

| 产品 | 架构 | 说明 |
| --- | --- | --- |
| 个人版桌面 | 原生 C/S | Swing 原生界面，进程内直接连接数据库；不启动浏览器、WebView、本地 Spring Boot 或 HTTP 服务 |
| 企业版 | B/S | Vue 3 前端 + Spring Boot 服务端，集中托管数据源、用户、权限、审批、审计与 AI |
| 企业移动端 | B/S 客户端 | Android / HarmonyOS / iOS 原生外壳通过系统 WebView 连接远端企业服务 |

桌面与企业服务共享 `core` 中的驱动、元数据、SQL 解析和审核能力，但拥有独立入口、状态存储和打包链。

## 个人版原生功能

- 原生数据库连接配置与对象导航树；
- 连接配置批量导入、导出，并由用户选择密码处理方式；
- SQL 多标签、结果表格、限行、取消、事务、CSV 导出；
- 字段、主键、DDL 和 ER 外键图；可手动采集选中范围并保存 JSON / Markdown 元数据快照；
- 9 类数据库驱动按需下载、隔离加载；
- 危险 SQL 静态审核与二次确认；
- AI 生成、解释、修复、优化与安全审查 SQL；元数据经预览和 Token 估算后显式附加；
- DeepSeek、百炼、OpenAI、GLM、豆包、Ollama 和自定义兼容 Provider；
- 数据库密码和 AI Key 在本机加密保存；
- AI 输出只作为建议，绝不自动执行。

## 企业版功能

- 工作空间与平台两级 RBAC；
- 数据源集中托管、授权与最小资源范围；
- 连接配置批量导入，以及经过审批、限时、一次性的数据源导出；
- SQL 审批、一次性导出、脱敏和审计；
- 企业 AI Provider 管理、手动元数据快照、显式 AI 附加与权限控制；
- SSH 隧道、后台任务、定时报表和 Webhook；
- Docker、Flyway、非 root 运行与生产安全门禁。

## 技术栈

| 模块 | 技术 |
| --- | --- |
| `core` | Java 17、JDBC、Maven Resolver、JSqlParser |
| `desktop` | Java Swing、JDK HttpClient、jpackage |
| `backend` | Spring Boot 3.2.5、Spring Security、JPA、Flyway |
| `frontend` | Vue 3.4、TypeScript、Vite、Element Plus、Monaco |
| `mobile` | Kotlin / ArkTS / Swift + 系统 WebView |
