# LyraDB · 天琴智库项目 Wiki

## 产品定位

LyraDB · 天琴智库是面向数据专业团队、可私有化部署的可信 AI 数据智库。它把多数据库、授权元数据、已验证知识和治理规则连接起来，让每个数据问题都得到有依据、可执行、可追溯的答案。

数据库导航、SQL 编辑器和结果网格继续作为人类检查、修改和接管 AI 任务的专业控制面。完整定义见 [产品定位](../docs/product/产品定位.md) 和 [产品战略](../docs/product/产品战略.md)。

当前支持 MySQL、PostgreSQL、Oracle、SQL Server、SQLite、ClickHouse、MaxCompute、MongoDB 和 Redis。

从 `3.0.1` 起，产品明确拆分为三种协同形态：

| 产品形态 | 架构 | 角色 |
| --- | --- | --- |
| 个人智库工作台 | 原生 C/S | 本地直连、多数据库工作流、个人智库助手与专业控制面 |
| 团队可信数据智库 | B/S | 团队知识、受控 Agent、Provider、权限、审批、评测与审计 |
| 移动治理伴侣 | B/S 客户端 | Android / HarmonyOS / iOS 安全外壳，承担审批、审计和任务接管 |

桌面与企业服务共享 `core` 中的驱动、元数据、SQL 解析和审核能力，但拥有独立入口、状态存储和打包链。

## 个人智库工作台

- 原生数据库连接配置与对象导航树；
- 连接配置批量导入、导出，并由用户选择密码处理方式；
- SQL 多标签、结果表格、限行、取消、事务、CSV 导出；
- 字段、主键、DDL 和 ER 外键图；可手动采集选中范围并保存 JSON / Markdown 元数据快照；
- 9 类数据库驱动按需下载、隔离加载；
- 危险 SQL 静态审核与二次确认；
- 智库助手生成、解释、修复、优化与安全审查 SQL；元数据经预览和 Token 估算后显式附加；
- DeepSeek、百炼、OpenAI、GLM、豆包、Ollama 和自定义兼容 Provider；
- 数据库密码和 AI Key 在本机加密保存；
- AI 输出只作为建议，绝不自动执行。

## 团队可信数据智库

- 工作空间与平台两级 RBAC；
- 数据源集中托管、授权与最小资源范围；
- 连接配置批量导入，以及经过审批、限时、一次性的数据源导出；
- SQL 审批、一次性导出、脱敏和审计；
- Ask Lyra、已验证知识、上下文回执和显式元数据范围；
- 受控只读计划、确认、执行前复检、取消与审计；
- AI Provider、私有模型策略、黄金集与质量评测；
- MaxCompute 分区、扫描量和成本专项证据；
- 独立身份、最小 Scope 的 REST/MCP Agent Gateway；
- SSH 隧道、后台任务、定时报表和 Webhook；
- Docker、Flyway、非 root 运行与生产安全门禁。

## 技术栈

| 模块 | 技术 |
| --- | --- |
| `core` | Java 17、JDBC、Maven Resolver、JSqlParser |
| `desktop` | Java Swing、JDK HttpClient、jpackage |
| `backend` | Spring Boot 3.2.5、Spring Security、JPA、Flyway |
| `frontend` | Vue 3.4、TypeScript、Vite、Element Plus、Monaco |
| `mobile` | Kotlin / ArkTS / Swift + 系统 WebView |

## 项目结构

```text
lyradb/
├── core/             # 共享驱动、模型、SQL 解析与审核

├── backend/          # 企业版服务端
├── frontend/         # 企业版 Web 前端
├── mobile/           # 企业 B/S 移动客户端
├── .github/workflows/
└── wiki/
```
